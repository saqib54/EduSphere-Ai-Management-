## ✨ Features

### 🏫 Principal / Admin Portal
| Feature | Description |
|---|---|
| 📊 **Dashboard** | Live KPI strip — students, teachers, attendance %, pending fees (PKR), upcoming exams |
| 📋 **Admissions Desk** | Online admission applications, approval workflow, status tracking |
| 👨‍🎓 **Student Directory** | Full CRUD — enrol, edit, archive students with class/section assignment |
| 👩‍🏫 **Teachers & Staff** | Staff management, subject allocation, contract details |
| 🏛️ **Classes & Subjects** | Multi-section setup, subject linking, timetable configuration |
| 💰 **Fees & Challans** | PKR fee plans, auto-generated challans, payment-proof upload & verification |
| 💳 **Financial Management** | Income/expense ledger, salary disbursement, budget summary |
| 📅 **Attendance** | Institution-wide daily attendance tracking with trend charts |
| 📑 **Assignments** | Create, distribute and review homework across classes |
| 🗓️ **Timetable** | Class-period scheduling per section and teacher |
| 📚 **Study Materials** | Upload and organise learning resources by subject |
| 📊 **Reports & Analytics** | Academic, financial and attendance reports with Recharts visualisations |
| ⚙️ **Settings** | School profile, academic years, branding |
| 🤖 **AI Assistant** | Context-aware AI drawer for quick school management queries |
| 📲 **AI WhatsApp Notices** | Bulk WhatsApp notification composer powered by AI |
| 👨‍👩‍👧 **HR & Payroll** | Teacher payslips, leave management, payroll reports |

### 👨‍🏫 Teacher Portal
| Feature | Description |
|---|---|
| 📊 **Dashboard** | Daily schedule, attendance summary, assignment overview |
| ✅ **Attendance Marking** | Quick student attendance per period with smart defaults |
| 📝 **Quizzes** | Create timed quizzes, auto-grade MCQs, review submissions |
| 📔 **Class Diary** | Post homework notes visible to students and parents |
| 📑 **Assignments** | Set, grade and return assignments with file upload support |
| 📊 **Exams & Results** | Enter marks, view result distributions |
| 📚 **Study Materials** | Upload PDFs, videos and links for students |

### 👨‍🎓 Student Portal
| Feature | Description |
|---|---|
| 🧠 **AI Radar Dashboard** | Personalised performance radar across subjects |
| ✅ **Active Quizzes** | Real-time quiz sessions with countdown timer |
| 📋 **Exam Results** | Grade sheets with percentage, GPA, remarks |
| 🧾 **Fee Challan** | View and download PKR fee challans, upload payment proof |
| 📔 **Class Diary** | View teacher diary and homework notes |
| 📚 **Study Materials** | Access teacher-uploaded resources |
| 🗓️ **Timetable** | Personal class schedule |

### 👨‍👩‍👧 Parent Portal
| Feature | Description |
|---|---|
| 📊 **Child Progress** | Academic performance, attendance rate, fee status |
| 📲 **Notifications** | Receive school announcements |
| 🧾 **Fee Payments** | View and pay fee challans |

## 🛠️ Tech Stack

| Layer | Technology |
|---|---|
| **Frontend** | React 19, Vite 6, CSS (custom design system) |
| **UI Components** | Phosphor Icons, Recharts |
| **Typography** | Inter (via @fontsource) |
| **Backend** | Node.js 20+, Express 5 |
| **Database** | SQLite (via `pg`-compatible driver, production-ready to swap to PostgreSQL) |
| **Auth** | JWT (`jsonwebtoken`), bcryptjs |
| **Security** | Helmet, express-rate-limit, express-validator |
| **File Uploads** | Multer |
| **Dev Tooling** | Concurrently, Puppeteer (screenshot capture) |

## 🚀 Getting Started

### Prerequisites

- **Node.js** 20 or newer → [Download](https://nodejs.org/)
- **Git** → [Download](https://git-scm.com/)

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/saqib54/EduSphere-Ai-Management-.git
cd EduSphere-Ai-Management-

# 2. Install dependencies
npm install

# 3. (Optional) Set up environment variables
cp .env.development .env
# Edit .env with your database / JWT config if needed

# 4. Run database migrations
npm run migrate

# 5. Start development server (API + Vite hot-reload)
npm run dev
```

Open **http://localhost:5173** in your browser.

## 🎨 Design System

EduSphere uses a custom design system built from scratch:

| Token | Value | Usage |
|---|---|---|
| `--primary` | `#4f6ef7` | Buttons, links, focus rings |
| `--accent` | `#f97316` | Active nav pill, tab underlines |
| `--canvas` | `#f4f5fc` | Workspace background |
| `--surface` | `#ffffff` | Cards, panels |
| Card radius | `16px` | All panels |
| Input radius | `10px` | Form fields |
| Button | `#4f6ef7 → #8b5cf6` | Gradient with shadow |

## 🔌 API Endpoints

The backend exposes a RESTful API at `/api`:

| Route | Description |
|---|---|
| `POST /api/auth/login` | JWT login |
| `GET /api/students` | List all students |
| `GET /api/teachers` | List all teachers |
| `GET /api/classes` | Classes & sections |
| `GET /api/attendance` | Attendance records |
| `GET /api/fees` | Fee plans & challans |
| `GET /api/exams` | Exams & results |
| `GET /api/quizzes` | Quiz management |
| `GET /api/assignments` | Assignments |
| `GET /api/timetable` | Class timetable |
| `GET /api/reports` | Analytics & reports |
| `GET /api/announcements` | School notices |
